# Memory Tools

This server provides 9 tools.

## Available Tools

- [`create-entities`](./create-entities.md) - Create multiple new entities in the knowledge graph
- [`create-relations`](./create-relations.md) - Create multiple new relations between entities in the knowledge graph. Relations should be in active
- [`add-observations`](./add-observations.md) - Add new observations to existing entities in the knowledge graph
- [`delete-entities`](./delete-entities.md) - Delete multiple entities and their associated relations from the knowledge graph
- [`delete-observations`](./delete-observations.md) - Delete specific observations from entities in the knowledge graph
- [`delete-relations`](./delete-relations.md) - Delete multiple relations from the knowledge graph
- [`read-graph`](./read-graph.md) - Read the entire knowledge graph
- [`search-nodes`](./search-nodes.md) - Search for nodes in the knowledge graph based on a query
- [`open-nodes`](./open-nodes.md) - Open specific nodes in the knowledge graph by their names
