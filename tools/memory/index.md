# Memory Tools

This server provides 9 tools.

## Available Tools

- [`create_entities`](./create_entities.md) - Create multiple new entities in the knowledge graph
- [`create_relations`](./create_relations.md) - Create multiple new relations between entities in the knowledge graph. Relations should be in active
- [`add_observations`](./add_observations.md) - Add new observations to existing entities in the knowledge graph
- [`delete_entities`](./delete_entities.md) - Delete multiple entities and their associated relations from the knowledge graph
- [`delete_observations`](./delete_observations.md) - Delete specific observations from entities in the knowledge graph
- [`delete_relations`](./delete_relations.md) - Delete multiple relations from the knowledge graph
- [`read_graph`](./read_graph.md) - Read the entire knowledge graph
- [`search_nodes`](./search_nodes.md) - Search for nodes in the knowledge graph based on a query
- [`visualize_graph`](./visualize_graph.md) - Visualize the knowledge graph as an interactive HTML UI.
