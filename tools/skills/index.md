# Skills Tools

This server provides 3 tools.

## Available Tools

- [`docs-to-files.fetch-and-store`](./docs-to-files.fetch-and-store.md) - Resolve a library id, fetch docs, and write a markdown file.
- [`fetch-and-store-documentation.fetch-and-store`](./fetch-and-store-documentation.fetch-and-store.md) - Download a URL and write its contents to a file.
- [`repo-insight.analyze-repo`](./repo-insight.analyze-repo.md) - Search docs and code graph for insights, then store a summary.
