# Conceptharvester Tools

This server provides 4 tools.

## Available Tools

- [`tag-chunk`](./tag-chunk.md) - Extract concepts from a single chunk (no DB resolution).
- [`tag-batch`](./tag-batch.md) - Extract concepts from multiple chunks (no DB resolution).
- [`harvest-chunk`](./harvest-chunk.md) - Extract and resolve concepts to weighted graph edges (requires DB).
- [`harvest-batch`](./harvest-batch.md) - Batch extract and resolve concepts to graph edges (requires DB).
